# adamkpn/homebrew-tap

Homebrew formulae for [adamkpn](https://github.com/adamkpn)'s tools.

## vdisplay

[vdisplay](https://github.com/adamkpn/vdisplay) runs any macOS app on a virtual display of any resolution and shows it in part of your screen.

```bash
brew install adamkpn/tap/vdisplay
```

Or tap once and install by name:

```bash
brew tap adamkpn/tap
brew install vdisplay
```

The formula installs the universal (Apple Silicon and Intel) binary from the vdisplay GitHub release. Each vdisplay release updates it automatically.
